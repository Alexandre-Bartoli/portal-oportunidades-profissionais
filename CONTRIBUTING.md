# Contribuições

Obrigado pelo interesse. Este repositório é uma prova de conceito em desenvolvimento.

1. Abra uma issue descrevendo o problema ou a melhoria proposta.
2. Antes de enviar novas integrações, documente o provedor, o método de acesso, os termos de uso e os limites das consultas.
3. Não inclua dados pessoais de candidatos nem credenciais.
4. Adicione testes automatizados para alterações na coleta e classificação.
5. Execute `python3 -m unittest discover -s tests -v` antes de propor modificações.

Não envie vagas fictícias como se fossem oportunidades reais.
