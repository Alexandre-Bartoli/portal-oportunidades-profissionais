# Segurança

Esta prova de conceito não está pronta para exposição à internet pública. Não abra o servidor para acesso externo sem acrescentar autenticação, proteção contra abuso, revisão das integrações, logs apropriados, monitoramento e requisitos de proteção de dados.

Em caso de falha de segurança, evite publicar detalhes exploráveis em issues públicas. Entre em contato com os responsáveis pelo repositório por um canal privado definido na publicação do projeto.

Nunca registre tokens, senhas ou dados pessoais de estudantes no código ou nos relatórios de execução.
